# CalorieToken Evidence Record Template

## MANDATORY

- Evidence ID: IMMUTABLE ID placeholder, not a legal conclusion
- Scope: CALORIETOKEN | ICTHENDRIKSE | CROSS-SCOPE | UNKNOWN
- Evidence Type: CORPORATE | KVK | LEGAL_AGREEMENT | AMENDMENT | TRANSFER | IP | TRADEMARK | DOMAIN | SOFTWARE | GITHUB | XRPL | BLOCKCHAIN | TOKEN | WALLET | FINANCIAL | TECHNICAL | REGULATORY | PRIVACY | SECURITY | PUBLICATION | SOCIAL | WEB_ARCHIVE | CORRESPONDENCE | RESEARCH | OTHER
- Title: Short descriptive title
- Description: Concise description of the evidence item
- Subject: What this evidence is about
- Source: Name of the source system or authority
- Source Type: official registry | signed document | user-provided document | website | GitHub | Git commit | XRPL | blockchain explorer | domain registry | trademark registry | public social post | archived web page | correspondence | AI-derived information | other
- Authority: The authority behind the source or record
- Original Location: Location of the authoritative original
- Access Classification: PUBLIC | INTERNAL | RESTRICTED | HIGHLY_RESTRICTED
- Evidence Classification: VERIFIED_PRIMARY | VERIFIED_SECONDARY | PUBLIC_CLAIM | INFERENCE | UNKNOWN | CONTRADICTED
- Verification Status: NOT_REVIEWED | PENDING | VERIFIED | PARTIALLY_VERIFIED | REJECTED | CONTESTED | NOT_APPLICABLE
- Preservation Status: ORIGINAL | ARCHIVE | DERIVED | SNAPSHOT | REFERENCE
- Review Status: DRAFT | UNDER_REVIEW | APPROVED | REJECTED | PENDING

Use only when relevant and supported by the actual evidence type:

- Contract Reference
- KVK Number
- Trademark Reference
- Domain Name
- XRPL Address
- Wallet Reference
- Token Reference
- Git Commit Hash
- Blockchain Transaction Hash
- Archive Snapshot Reference
- Person or Organization Association
- Case or Filing Number

## Notes

- The Evidence Register is metadata / provenance / index only.
- It does not replace the authoritative original.
- Scope does not establish legal ownership.
- Date fields are not universal; they are conditional and evidence-specific.
- Sensitive originals must not be stored in public GitHub.
- AI may index and suggest, but must not silently alter evidence or make legal conclusions.
