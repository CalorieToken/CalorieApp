# CalorieHelp and the new food steps

Updated 15 September 2026 for live Site Style 1.4.46.

Open CalorieHelp on the CalorieToken website and choose **Find foods with USDA**
or **Also compare**. The same eleven language choices are available as in the
food application. The original CalorieHelp character remains the guide.

The USDA guide explains how to choose a source record, check its preparation
description and enter edible grams. The comparison guide explains how to
inspect another food's own source and nutrition before choosing an amount.
Similar-food suggestions are ideas to inspect, not medical or dietetic advice.
Ingredients, allergens and preparation can differ. Choosing a food opens the
existing portion flow; saving still needs sign-in and explicit confirmation.

Project history describes CAL on the XRP Ledger since 2021, earlier Testnet
and mobile experiments, today's food features and the broader Web3 roadmap.
A roadmap ambition is not evidence that a planned service is already available.

CalorieHelp uses fixed answers from the linked public project sources. It does
not create support tickets or keep a chat history. Questions are processed in
the page and then cleared. Device dictation, when used, is handled separately
by the user's device or keyboard provider.

## Release evidence

The update changes the help data, help script, targeted presentation CSS and
Site Style version strings. All eleven language sets were exercised using the
actual script, including topic selection, question routing, language changes
and older cached data. The four WordPress editor saves were checked against
the prepared source. Live version 1.4.46 and the new answers were verified.

Newly selected replies receive focus and are brought into the help panel's
view. The character header remains visible. Narrow-layout rules constrain the
panel and wrap its controls. These changes do not constitute a full mobile
acceptance of every WordPress page or a physical-device test.

Source snapshots contain only the changed files and selected baseline files;
they are not a complete installable plugin. The repository's older full plugin
must not overwrite the newer live installation.
