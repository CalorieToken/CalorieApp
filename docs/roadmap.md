# CALORIEAPP ROADMAP

## PHASE 1 - MVP (ACTIVE)

Objective: Build a functional food tracking system.

Includes:

- Open Food Facts integration
- Food search UI
- Nutrition display (calories/macros)
- Backend food logging system
- Basic API communication frontend <-> backend

Constraints:

- No blockchain
- No wallets
- No decentralized storage
- No financial logic

## PHASE 2 - WALLET EXTENSION (FUTURE)

Objective: Optional non-custodial blockchain interaction.

Includes:

- Xaman Wallet authentication
- User-signed XRPL transactions

## PHASE 3 - DECENTRALIZED MEDIA (FUTURE)

Objective: Optional media decentralization.

Includes:

- IPFS integration for food images/uploads

## PHASE 4 - IMMUTABLE LOGGING (FUTURE)

Objective: Optional audit system.

Includes:

- BigchainDB-based event logging

## GLOBAL RULE (HIGHEST PRIORITY)

At no stage may CalorieApp become custodial or handle user funds directly.

All blockchain interactions MUST remain user-signed and externally controlled.
